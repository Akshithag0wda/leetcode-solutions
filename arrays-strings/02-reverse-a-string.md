# Reverse a String

**Difficulty:** Easy

**Link:** https://leetcode.com/problems/reverse-string/

## Approach

I used two pointers, one starting from the beginning and one from the end of the string. The characters at these positions are swapped until the pointers meet.

## Complexity

**Time Complexity:** O(n)

**Space Complexity:** O(1)
