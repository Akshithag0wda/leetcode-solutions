# Valid Anagram

**Difficulty:** Easy

**Link:** https://leetcode.com/problems/valid-anagram/

## Approach

I used a frequency array to count how many times each character appears in both strings. If the character counts are the same for both strings, they are anagrams.

## Complexity

**Time Complexity:** O(n)

**Space Complexity:** O(1)
