# Binary Search

**Difficulty:** Easy–Medium

**Link:** https://leetcode.com/problems/binary-search/

## Approach

I used two pointers, left and right, to search the sorted array. The middle element is checked and the search range is reduced by half each time.

## Complexity

**Time Complexity:** O(log n)

**Space Complexity:** O(1)

## Notes

The solution was tested locally with two test cases and was accepted on LeetCode.
