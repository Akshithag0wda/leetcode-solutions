# Valid Parentheses

**Difficulty:** Easy–Medium

**Link:** https://leetcode.com/problems/valid-parentheses/

## Approach

I used a stack to store opening brackets. Whenever a closing bracket is found, I check whether it matches the most recently stored opening bracket.

## Complexity

**Time Complexity:** O(n)

**Space Complexity:** O(n)

## Notes

The solution was tested locally with two test cases and was accepted on LeetCode.
